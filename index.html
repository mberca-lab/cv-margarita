05 / How I work

Start with the question. Stay with the evidence.

?

Make the question answerable.

Clarify the decision, test the measurement and choose an analytical approach that fits the problem.

↗

Make the answer useful.

Explain the findings, their limitations and the practical options—not just the statistical result.

↻

Make the work reusable.

Build documented methods, reusable code and clear handovers so recurring work can be rerun rather than rebuilt.
